Supercharge Chrome's tabs

Chrome cycles tabs in tab-strip order. TabCircle makes ⌃⇥ cycle them by recent use with a thumbnail switcher — plus idle-tab cleanup and pins that survive restarts.

macOS 14+ Chrome 116+ Open Source · MIT Free
Download Install Guide

Hold ⌃ and tap ⇥ to browse, release to switch — or just click a card.

Features

From switching to managing — each piece done properly.

Most-recently-used order

⌃⇥ takes you to the tab you were last on, not the one next to it in the strip.

Stable A↔B toggling

Tap again and you are back. While held, only a cursor moves and the switch commits on release, so tabs you merely passed are not recorded as used.

Page thumbnails

Every card carries a live screenshot, so you recognise tabs by what they look like.

Keyboard, arrows, mouse

⌃⇥ and ⌃⇧⇥ move back and forth, arrow keys work while held, or click any card directly.

Scoped per window

The switcher lists only the tabs of the window in use, and each window keeps its own history. Can be turned off in settings.

Pins that persist

Pinned tabs are remembered and kept in two-way sync: after a Chrome restart they come back pinned, restored to the last page you visited.

Menu bar tab list

Every tab across every window, one hover away in the menu bar — grouped by window with last-used times; click to bring Chrome forward on that tab.

Close while switching

Hover a switcher card for an ✕ and close tabs as you cycle, without breaking the round. Off by default, enable in settings.

Tab lifetime

12 hours, 24 hours or 7 days — idle tabs get cleaned up automatically; pinned, audible, grouped and current tabs are never touched. Off by default.

Custom shortcuts

Record a shortcut for pin / unpin current tab. It only fires while Chrome is frontmost — other apps never see it.

Never silently broken

If either half is unavailable, ⌃⇥ falls through to Chrome's built-in switching instead of becoming a dead key.

How it works

TabCircle runs as two parts that talk over a loopback WebSocket.

┌─────────────────────────┐         ┌──────────────────────────┐
│  Chrome Extension (MV3) │  loop   │  Swift Helper            │
│                         │◄──ws───►│                          │
│  · tabs.onActivated     │  :41573 │  · CGEventTap  (⌃⇥)      │
│  · captureVisibleTab    │         │  · NSPanel     (overlay) │
│  · tabs.update          │         │  · MRU state machine     │
└─────────────────────────┘         └──────────────────────────┘
The extension cannot read the keyboard. Tab was removed from the supported-key list of chrome.commands back in Chrome 33, so no extension can bind ⌃⇥. That is why a native process is required.
The helper cannot read the tabs. Titles, ordering, thumbnails and switching all go through the chrome.tabs API. That is why an extension is required.

Installation

Requires macOS 14+ and Chrome 116+.

  1. Download and install

    Download the DMG from Releases and drag TabCircle.app into Applications. If the first launch says the developer cannot be verified, right-click TabCircle in Applications and choose Open — the app carries no paid Apple signature; the read-me inside the DMG covers the details. Building from source is documented in the repository README.

    Download the App

  2. Install the extension

    Download and unzip the extension, open chrome://extensions, turn on Developer mode, click Load unpacked and pick the unzipped folder. The extension isn't on the Web Store, so this developer-mode step is required — the guide walks through it.

    Download Extension Install Guide

  3. Grant Accessibility permission

    The first launch shows a guided overlay — drag the TabCircle icon from the overlay into the Accessibility list, and the app relaunches itself once the permission takes effect. You can also enable it manually under System Settings → Privacy & Security → Accessibility.

  4. Start using it

    When the menu bar icon brightens and its first line reads Connected, both halves are talking. Click the TabCircle icon in the Chrome toolbar to open settings.

    The log file lives at ~/Library/Logs/TabCircle/tabcircle.log — start troubleshooting there.

Shortcuts

Active while Chrome is frontmost.

Keys Result
⌃ ⇥ Switch to the previously used tab
⌃ ⇥ ⇥ Hold ⌃ and keep tapping to move further back
⌃ ⇧ ⇥ Move in the opposite direction
⌃ ← → Move the cursor with arrow keys while ⌃ is held
⌃ + click Switch straight to the card you click
Custom Pin / unpin the current tab (record it under Settings → Shortcuts)
