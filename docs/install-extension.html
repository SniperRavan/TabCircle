Installing the extension

The TabCircle Bridge extension isn't on the Chrome Web Store yet, so it installs via Developer mode — a one-time setup.

  1. Download and unzip

    Download TabCircle-Extension.zip and double-click to unzip the TabCircle-Extension folder. Keep it somewhere permanent (e.g. Documents) — Chrome loads the extension from this folder, so deleting it disables the extension.

    Download the extension

  2. Open the extensions page

    Type chrome://extensions in the address bar, or use Menu → Extensions → Manage Extensions.

  3. Turn on Developer mode

    Flip the Developer mode toggle in the top-right corner; a new row of buttons appears.

  4. Load the extension

    Click Load unpacked and select the TabCircle-Extension folder from step 1. When TabCircle Bridge appears in the list, you're done.

  5. Confirm the connection

    With the TabCircle app running, the menu bar icon brightens and its first line reads Connected. Hold ⌃ and tap ⇥ to bring up the switcher.

Upgrading: when a TabCircle release notes an extension update, download the new zip, replace the folder's contents, then hit the refresh button (↻) on the TabCircle Bridge card in chrome://extensions.
